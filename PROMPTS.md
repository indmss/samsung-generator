# Использованные промпты

Инструмент собирался итеративно в диалоге с AI-агентом (Claude).
Ниже — мастер-промпт, который воспроизводит результат «в один запрос»
(п.2 ТЗ, критерий «Промпт-инжиниринг»), и краткая история реальных
шагов уточнения.

## Мастер-промпт (воспроизводимый, «один запрос → 4 креатива»)

```
Ты — инструмент автоматизации маркетинговых креативов Samsung.

На входе: Excel-файл с вкладками
  «1. Вводные (Input)»            — код модели, категория, цены,
                                     скидка, слоган, 3 фичи, бейдж,
                                     кэшбэк/рассрочка, канал
                                     (+ опционально колонки *_KZ)
  «5. Цены по ритейлерам»         — Model_Code, Retailer, Price_New,
                                     Promo_Text (опционально)

Задача: для указанной модели (или для ВСЕХ моделей разом) построить
4 формата креатива — Feed Square 1080×1080, Feed Portrait 1080×1350,
Stories/Reels 1080×1920, Display 1200×628 — строго по генеральному
шаблону:

  заголовок+сумма выгоды        — верхний левый угол, крупно
  иконки фич                    — левая колонка (в Display — в ряд)
  цена (от ₸/мес · цена · -% · старая цена) — под фичами, слева
  товар                         — правая часть, по диагонали
  название модели                — над продуктом
  бейдж объёма                  — чёрный круг у продукта
  логотип Samsung               — верхний правый (кроме Stories)
  плашка оплаты                 — нижняя часть, на всю ширину

Соблюдай safe zone и clear space гайдлайна Samsung (точные пиксели,
не проценты): Square 64px, Portrait 64–80px, Stories top 250/bottom
350/side 72px без лого, Display 60px; clear space лого = 0.5× его
высоты. После отрисовки — проверь фактические границы каждого
текстового/лого-слоя против этих значений и сообщи о нарушениях.

На выходе для каждого формата: PSD (РЕАЛЬНО многослойный — отдельный
слой на каждый смысловой блок, не один плоский слой) + JPG (финал),
плюс текстовый бриф на модель. Если lang=KZ — переведи заголовок,
категорию, фичи и текст плашки (используй колонки *_KZ, если есть,
иначе — RU как запасной вариант). Если указан ритейлер — подставь его
цену/промотекст из листа «5. Цены по ритейлерам», иначе — базовую цену.

Заверни всё в offline GUI-приложение (tkinter): выбрать Excel → выбрать
модель/язык/ритейлер → «Сгенерировать» или «Сгенерировать ВСЕ модели» →
файлы в папке на Рабочем столе. Без терминала, без интернета.
```

## Реальная последовательность уточняющих промптов

1. Первая версия: базовая отрисовка 4 форматов из Excel, плоский JPG,
   заглушка вместо PSD, GUI с одной кнопкой генерации.
2. «Добавь кнопку "Сгенерировать все модели"» → пакетный режим по всем
   строкам вкладки «Вводные».
3. «Сделай чтобы работал перевод, многослойный PSD, ритейлер-
   специфичные цены, safe-zone валидатор; интерфейс — солидный, как
   полноценное ПО» → на этом шаге выяснилось, что предыдущая версия
   только заявляла эти фичи в комментариях, но реально их не делала
   (retailer/lang принимались, но не использовались; PSD был плоским).
   Переписаны: `psd_writer.py` (настоящий многослойный PSD с RLE-
   сжатием, проверен независимым парсером ImageMagick), локализация
   через колонки `*_KZ`, подстановка цены по ритейлеру через
   отдельный лист Excel, валидатор safe zone/clear space с допуском на
   антиалиасинг, переработан GUI (брендовые цвета, статус-лог, таблица
   результатов вместо списка, прогресс-бар, работа в фоновом потоке
   чтобы не подвисало окно).
4. По ходу отладки: найден и исправлен баг — служебная строка-
   примечание в Excel («Розовым — главная модель…») попадала в
   пакетную генерацию как «модель» с нулевой ценой → добавлена
   фильтрация валидных строк по формату кода и наличию цены.
