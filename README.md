# Samsung Creative Generator

Автоматическая генерация рекламных креативов (Feed Square, Feed Portrait,
Stories/Reels, Display) из одного Excel-файла — по гайдлайну Samsung
(safe zone, clear space, генеральный шаблон расстановки элементов).

Тестовое задание №1 — AI Marketing Manager.

---

## Что делает инструмент

Из одного Excel-файла с моделями и акциями → на выходе, для выбранной
модели (или сразу для всех):

- **4 формата** креатива: Feed Square (1080×1080), Feed Portrait
  (1080×1350), Stories/Reels (1080×1920), Display (1200×628)
- каждый — в **PSD (редактируемый, многослойный)** и **JPG (финал)**
- **бриф на модель** (`_brief.txt`) — текстом, автоматически из тех же
  данных Excel
- проверка **safe zone и clear space** перед сдачей (встроенный
  валидатор, результат — в брифе и в логе программы)

Бонусы из п.8 ТЗ, которые реализованы:

- обработка всего Excel разом («Сгенерировать ВСЕ модели»)
- мультиязычность RU / KZ из одних и тех же данных
- автоматическая проверка safe zone и позиции логотипа перед экспортом
- цены/акции по ритейлеру (ALL / Kaspi / Sulpak / Mechta / Technodom)
- простой offline-интерфейс без терминала (п.11 ТЗ)

Не реализовано (осознанно, из-за срока):

- 5-й формат Video (1920×1080)
- реальные фото товаров — сейчас векторные силуэты (стиральная машина/
  холодильник/телевизор). Программа автоматически подхватит настоящее
  PNG-фото без фона, если положить его в `assets/<Код_модели>.png` —
  никакой правки кода не нужно.
- KZ-переводы в приложенном Excel — рабочие, но черновые (сделаны для
  демонстрации механизма локализации). Перед реальным запуском их
  должен вычитать носитель/переводчик.

## Как запустить (без сборки, для разработки)

```bash
pip install pandas pillow openpyxl
python3 samsung_generator.py
```

1. «Выбрать Excel» → указать файл шаблона (по умолчанию ищет
   `data/samsung-creative-brief-template.xlsx`)
2. Выбрать модель (или добавить новый код кнопкой «+ Добавить код» —
   она подставится, если такой код есть в Excel), язык, ритейлера
3. «Сгенерировать модель» — 1 модель, «Сгенерировать ВСЕ модели» —
   весь файл разом
4. Результат — папка `Samsung_Output` на Рабочем столе, там же список
   файлов и кнопка «Открыть папку» внутри программы

## Как собрать .app (macOS, offline-программа для дизайнера, п.11 ТЗ)

```bash
pip install pyinstaller
pyinstaller Samsung_Generator.spec
```

Готовое приложение — в `dist/Samsung Generator.app`. Работает без
интернета: данные (Excel, коды моделей) читаются локально, наружу
ничего не уходит.

## Структура Excel-шаблона

- **1. Вводные (Input)** — модели: код, категория, цены, скидка,
  слоган, фичи, бейдж, кэшбэк/рассрочка, канал. Плюс колонки `*_KZ`
  для казахской версии (если для языка KZ колонка пустая — программа
  сама берёт русский текст, ничего не ломается).
- **2. Форматы (Specs)** / **3. Маппинг (Mapping)** — справочные,
  как в исходном ТЗ, программой не читаются напрямую (логика
  расстановки зашита в `generator.py` по этим правилам).
- **4. Результат (Output)** — чек-лист сдачи.
- **5. Цены по ритейлерам** (добавлен) — `Model_Code`, `Retailer`,
  `Price_New`, `Promo_Text`. Если для ритейлера нет строки (или выбран
  `ALL`) — используется базовая цена из «Вводные».

## Как добавить новую модель в следующем месяце

Просто дописать строку в лист «1. Вводные (Input)» — код должен быть
на латинице/цифрах (со служебными пометками вроде «Розовым — главная
модель…» программа больше не путает: строки без валидного кода или
без цены автоматически отбрасываются, и раньше именно из-за этого
батч-режим генерировал баннеры с нулевой ценой на несуществующей
«модели»). Для реального фото — положить `<Код>.png` в `assets/`.
Никаких изменений в коде не требуется — это и есть воспроизводимость
(п.7 ТЗ, критерий «Воспроизводимость»).

## Технические детали

- **Многослойный PSD** — пишется вручную по бинарной спецификации
  Adobe (`psd_writer.py`), без сторонних библиотек (офлайн-требование
  п.11 ТЗ исключает интернет-зависимые пакеты вроде `psd-tools`).
  Каждый смысловой блок (фон, товар, лого, заголовок, фичи, цена,
  плашка оплаты, модель/бейдж) — отдельный слой, сжатый PackBits (RLE).
  Проверено независимым парсером (ImageMagick `identify`), не только
  собственным кодом.
- **Safe zone / Clear Space валидатор** — после отрисовки каждого
  формата проверяет фактические границы текстовых слоёв и лого против
  пиксельных значений гайдлайна (допуск 2px на антиалиасинг), плюс
  зазор товар↔лого ≥ 0.5× высоты лого. Нарушения попадают в лог
  программы и в бриф.
- Стек: Python, Pillow (растровая отрисовка), pandas/openpyxl (Excel),
  tkinter (интерфейс), PyInstaller (сборка .app).

## Известные ограничения

- Интерфейс (tkinter) не тестировался визуально в песочнице без
  дисплея — синтаксис и логика проверены, но перед демонстрацией стоит
  один раз прогнать глазами и пересобрать `.app`.
- PSD пишется без сжатия финального сведённого превью (для надёжности
  открытия в любых версиях Photoshop) — из-за этого файлы чуть тяжелее,
  чем могли бы быть.
